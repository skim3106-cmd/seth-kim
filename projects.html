How OTA works

Deskbuddy

Connect Deskbuddy and your computer to the same Wi-Fi network. Arduino IDE discovers its network port; choose that port and upload as usual. The OTA password is managed in Deskbuddy settings (default: deskbuddy123).

TamaPets-CYD

Pair with TamaPets-CYD in a Bluetooth serial app. Send WIFI_SSID=..., WIFI_PASS=..., OTA_PASS=your-password (8+ characters), then WIFI_CONNECT. On the same Wi-Fi network, choose the TamaPets network port in Arduino IDE to upload. Use OTA_STATUS to see its IP.

OTA sends only a firmware update over your local network; the USB installer is for first install or recovery. Both devices must use the partition layout included in their USB image for OTA updates to fit.
